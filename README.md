# متقن — مقرأة القرآن الكريم

منصة تعليمية إلكترونية متخصصة في تعليم القرآن الكريم عن بُعد، مبنية باستخدام Next.js (App Router) وTypeScript وTailwind CSS.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البنية

- `app/` — صفحات المشروع (الرئيسية، البرامج، المعلمون، المقالات، عن متقن، التواصل، تسجيل الدخول، إنشاء حساب، لوحتا تحكم الطالب والمعلم)
- `components/` — مكونات مشتركة (الهيدر، الفوتر، الأيقونات، مكونات لوحات التحكم)
- `data/` — بيانات وهمية للبرامج والمعلمين والمقالات
- `lib/` — منطق الحجز (تقويم وحالة الحصص) المخزّن في `localStorage`

## نظام التصميم

الألوان والخطوط والزوايا والظلال معرّفة في `tailwind.config.ts` و`app/globals.css` وفق هوية متقن البصرية (خلفية كريمية، لمسات ذهبية، خط Tajawal، اتجاه RTL بالكامل).
