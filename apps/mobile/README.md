# تطبيق متقن (React Native / Expo)

تطبيق أندرويد (ويمكن iOS لاحقًا) حقيقي، منفصل عن موقع Next.js، مبني بـ
Expo + Expo Router، ويتصل بنفس مشروع Supabase الذي يستخدمه الموقع. هذا
أول إصدار ويغطي المسار الأساسي للطالب:

- تسجيل الدخول (نفس حسابات Supabase Auth المستخدمة في الموقع)
- تصفح البرامج والدورات داخلها (نفس بيانات `data/programs.ts` في الموقع،
  منسوخة محليًا إلى `lib/programs.ts` حاليًا)
- عرض الحلقات الجماعية والانضمام إليها/الانسحاب منها (نفس جدولي
  `group_sessions` و`group_enrollments`)
- الدخول إلى غرفة الفيديو الخاصة بكل حلقة (Jitsi، بنفس اسم الغرفة الذي
  يستخدمه الموقع، عبر WebView)

لوحات المعلم والمشرف ما زالت فقط على الموقع؛ يمكن إضافتها لاحقًا بنفس
الطريقة.

## التشغيل محليًا

```bash
cd apps/mobile
npm install
cp .env.example .env.local   # ثم عبّئ EXPO_PUBLIC_SUPABASE_URL/ANON_KEY
                              # بنفس قيم مشروع Supabase الذي يستخدمه الموقع
npx expo start
```

افتح تطبيق **Expo Go** من Google Play على جوالك وامسح رمز QR الذي يظهر
في الطرفية. لا حاجة لبناء نسخة مخصصة (dev client) لهذا الإصدار — كل
الحزم المستخدمة (بما فيها WebView) متوافقة مع Expo Go مباشرة.

## بناء نسخة حقيقية (.aab) لرفعها على Google Play

يتم البناء عبر خدمة EAS السحابية من Expo (لا حاجة لـ Android Studio أو
اتصال بخوادم Google من هنا، لأن الحساب السحابي يقوم بالبناء):

```bash
npm install -g eas-cli   # أو npx eas-cli
eas login                # يحتاج حساب Expo مجاني
eas build:configure
eas build --platform android --profile production
```

سيعطيك EAS رابطًا لتحميل ملف `.aab` جاهز لرفعه على Google Play Console،
بنفس الخطوات المذكورة في `android/README.md` لتطبيق TWA (حساب Play
Console، Play App Signing، إلخ). **ملاحظة:** حزمة أندرويد لهذا التطبيق
(`site.motqen.app`) مختلفة عن حزمة تطبيق TWA الموجود مسبقًا
(`site.motqen.twa`) لتجنب أي تعارض بينهما إلى أن يتقرر أيهما يُنشر
نهائيًا على المتجر.

## ملاحظات فنية

- **الفيديو:** يُفتح كل اجتماع داخل WebView يحمّل رابط الغرفة على
  `meet.jit.si` مباشرة (نفس ما يفعله الموقع)، مع نفس دالة تسمية الغرف
  (`lib/jitsi.ts`) بحيث تتطابق أسماء الغرف مع الموقع تمامًا لأي حلقة.
- **البيانات:** `lib/programs.ts` نسخة يدوية من بيانات البرامج على
  الموقع؛ أي تعديل مستقبلي على البرامج في الموقع يحتاج تحديثًا مطابقًا
  هنا حتى تُستخرج البيانات المشتركة إلى حزمة واحدة.
- **التوجيه:** يُستخدم Expo Router (توجيه بالملفات، شبيه بـ Next.js)
  ضمن مجلد `app/`.
